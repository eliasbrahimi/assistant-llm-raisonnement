# Sorties d’évaluation

`outputs/sample/` contient des exemples versionnés pour comprendre le format attendu.

`outputs/local/` est réservé à vos exécutions locales. Son contenu est ignoré par Git, sauf `.gitkeep`.

Ne stockez pas de données personnelles, de secrets, de copies d’étudiants ou d’exports fournisseurs dans ce dossier.
